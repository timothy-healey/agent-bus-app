What changes per tab

Live log

  • Streaming Claude output as it works
  • Auto-scrolls; pin to top to read earlier
  • Goes static once task is done

Artifact

  • Rendered markdown of the spec/plan/critique this card produced
  • Read-only by default; "edit" button for operator to fix typos before next stage picks it up
  • Version dropdown for revise loops (v1, v2, v3)

Parent docs

  • The artifacts upstream of this card (topic → analysis → spec → plan)
  • Click to open any in a side-by-side view
  • Helps reviewers see context without leaving the card

Review

  • Only present for cards that have gone through a reviewer
  • Findings list with status (open / resolved / deferred)
  • For Gate cards: approve / revise / reject buttons live here
