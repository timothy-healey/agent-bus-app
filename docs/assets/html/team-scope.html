What this generates at launch

When this worker spawns, the Rust backend writes a per-invocation settings file and constructs the claude args:

# ${runtime}/research-T-042.settings.json (generated, ephemeral)
{
  "permissions": {
    "allow": [
      "Read(/Users/tim/splose/splose-monorepo/**)",
      "Read(/Users/tim/agent-bus/artifacts/analyses/**)",
      "Write(/Users/tim/agent-bus/teams/research/outbox/**)",
      "Write(/Users/tim/agent-bus/artifacts/analyses/**)",
      "Write(/Users/tim/agent-bus/gates/needs-human/**)",
      "Write(/Users/tim/splose/splose-monorepo/docs/critique-*.md)",
      "Skill(ddd-council:*)",
      "Bash(ls:*)",
      "Bash(cat:*)",
      "Bash(rg:*)"
    ],
    "deny": [
      "Write(/Users/tim/splose/splose-monorepo/**)",
      "Read(/Users/tim/.aws/**)",
      "Read(/Users/tim/.ssh/**)",
      "Read(/Users/tim/splose/splose-monorepo/.env*)",
      "Bash(git push:*)",
      "Bash(rm -rf:*)"
    ]
  }
}

# command line
claude --print \
  --settings ${runtime}/research-T-042.settings.json \
  --add-dir /Users/tim/splose/splose-monorepo \
  --add-dir /Users/tim/agent-bus/artifacts/analyses \
  --add-dir /Users/tim/agent-bus/gates/needs-human \
  --permission-mode acceptEdits \
  --output-format stream-json \
  --verbose \
  --cwd /Users/tim/agent-bus/teams/research/working/ \
  "Process the task file at: T-042-imports-followups-01.md"

Default scopes per shipped team

Team Read Write Tools
research target_repo, parent_artifacts artifacts/analyses, target/docs/critique-* Read/Write/Edit/Grep/Bash(ro)
spec-writers artifacts/analyses, target_repo (ro) artifacts/specs Read/Write/Edit/Grep
spec-reviewers artifacts/specs, target_repo (ro) artifacts/reviews, target/docs/vet-* Read/Write/Edit/Grep
implementers artifacts/plans, target_repo worktrees/<id>/** only Read/Write/Edit/Bash(git:*; pnpm:*; test:*); deny git push
impl-reviewers worktrees/<id>, artifacts/plans artifacts/reviews Read/Grep/Bash(git diff/log:*)

Implementer is the only team with target_repo write — and only into its worktree, never the main checkout. git push is denied at the tool level so even an off-script claude can't reach the remote.

Optional v2: OS-level sandbox

For belt-and-braces beyond Claude's permission system, wrap each claude --print invocation in sandbox-exec (macOS) or bubblewrap (Linux). The Rust backend generates the sandbox profile from the same scope config. Defense-in-depth: if Claude's permissions are bypassed somehow, the OS kernel stops the worker reaching outside its sandbox.

Not v1. Mention it in the spec as a hardening path.
