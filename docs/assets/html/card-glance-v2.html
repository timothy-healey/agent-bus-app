How it gets measured

Workers invoke claude --print --output-format stream-json. Each response chunk carries an usage object with input_tokens + output_tokens + cache_creation_input_tokens + cache_read_input_tokens. The Rust backend tails the stream, sums them per-task across attempts, and persists into the task row in SQLite. Live updates flow to the frontend via WebSocket.

Card pill shows combined input + output (excluding cache reads to keep the number representative of what's being billed). Detail tab can break it down into input / output / cache / model and show USD using your configured pricing table.
