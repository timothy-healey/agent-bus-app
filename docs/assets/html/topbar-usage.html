how it's computed
Every claude --print --output-format stream-json emits usage per response chunk: input_tokens, output_tokens, cache_creation_input_tokens, cache_read_input_tokens. The Rust backend tails the stream, persists a row per chunk to SQLite usage_log(ts, team, task_id, tokens, model), and the topbar widget queries the last 5h.

The "% of window" assumes a configurable budget per user (default: 2.6M tokens / 5h ≈ Pro plan rough estimate; user adjusts in settings if they're on Max or API). Anthropic doesn't expose the actual subscription quota via API, so this is an estimate — useful as a guide, not a hard number.
